# Facebook+ Manager

Facebook+ Manager is a one-tap fork of [Morphe Manager](https://github.com/MorpheApp/morphe-manager) that patches a Facebook APK you download into **Facebook+**, using [HushFacebook](https://github.com/SysAdminDoc/HushFacebook) patches.

This is not Morphe. It is a modified GPLv3 program published by 8BiT Softworks. See `NOTICE`.

## What it does

1. Install Facebook+ Manager.
2. Tap **Make Facebook+**.
3. Download the pinned Facebook file from APKMirror (the app opens the page).
4. Manager patches it on your phone with HushFacebook defaults and installs **Facebook+**.

Facebook+ keeps package `com.facebook.katana`. We never ship Meta's APK.

## Pins (HushFacebook v0.18.0)

- Facebook `584.0.0.51.56` (`475817393`), `arm64-v8a`, `480dpi`
- Patch source: `SysAdminDoc/HushFacebook` only
- Device: Android 11+, 64-bit
